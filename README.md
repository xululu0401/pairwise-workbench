# 组合验收台
独立静态网页，无依赖、无模型调用。把2–6个独立分类因素（各2–5值）转换为两两覆盖清单，记录人工测试状态，导出CSV、Markdown、JSON备份与PNG概览。

## 使用
打开index.html，载入或填写因素，生成清单；在真实应用中执行每行条件的业务流程后选择状态。修改因素会清空旧状态。勾选本机保存才写入localStorage；取消会移除本工具记录。JSON备份可跨设备导入，100KB上限。

默认网页场景：3×2×2×2=24种全组合，确定性贪心生成6条用例，覆盖全部30个两两值对。不是24种全组合全覆盖。生成计划始终与执行记录区分；失败也计已执行，不计通过。

## 模型与限制
全枚举候选，再重复选择新覆盖值对最多的候选，平局按输入枚举顺序选择。保证所填独立因素的两两覆盖，不保证最小用例集；不支持不可能组合约束，不保证3个以上因素交互，无自动执行、无业务断言。

## 开发
`node build.cjs` 将core.js和ui.js打包进template.html，得到单文件index.html。
`node --test tests/core.test.cjs`：10项测试，包括180组随机场景逐值对穷举校验、最大15625候选、备份/非法输入/CSV转义。

封面为自制SVG转PNG；结果卡由Canvas生成，无付费生图服务。输入渲染用textContent；CSV对常见公式前缀添加单引号，导入严格校验再重算。网络托管服务仍会记录通常的访问日志，本应用不上传输入内容。
